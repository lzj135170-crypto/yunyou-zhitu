# ⚠️ 上面这一行【不能删】，删了 pip 就会读不动这个文件。
#
# 原因：pip 读 requirements 文件时用的是系统本地编码（中文 Windows 上是 cp936/GBK），
# 不是 UTF-8。而本文件是 UTF-8 保存的、又带中文注释，于是那些中文字节会被
# 强行按 GBK 解析。多数情况下碰巧能凑成合法的 GBK 双字节，看起来没事；
# 但只要出现一个凑不上的字节序列，pip 就直接抛
#   UnicodeDecodeError: 'gbk' codec can't decode byte 0xa3 ...
# 整个安装失败。【这个坑真实触发过】：加了「向量检索 + 嵌入」这行注释后，
# 「检」字的 UTF-8 字节 \xe6\xa3\x80 里 \x80 落单，pip 当场崩。
#
# 带编码声明后 pip 会按 UTF-8 解码（实测 100+ 行全部正确解析）。
# 也可以把注释改成纯英文来绕开，但那样会丢掉下面 torch 和 Milvus 那两段的说明，
# 而它们记录的是会让人踩坑的差异（CPU 版 torch、Milvus standalone 拉不到镜像）。

# ---------- RAG：向量检索 + 嵌入 ----------
#
# ⚠️ 下面这行 extra-index-url 不能删，它决定了装到的是 GPU 版还是 CPU 版 torch。
#
# PyPI（以及清华源）上 Windows 的 torch 轮子【只有 CPU 版】，124MB，不带任何
# nvidia-* 依赖。装上去不报错、代码也能跑，但 torch.cuda.is_available() 是 False，
# 嵌入编码会退回 CPU——安静地慢十几倍，很难联想到是装错了包。
# CUDA 版只在 PyTorch 自己的索引里，文件名带 "+cu130" 后缀，体积 1.9GB。
#
# 本项目实测：download.pytorch.org 可达（7.3 MB/s），
# 而国内的 aliyun / SJTU 镜像反而只有 0.29 MB/s，所以直接用官方源更快。
#
# 验证装对了没：python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
# 期望输出 2.14.1+cu130 True
--extra-index-url https://download.pytorch.org/whl/cu130
